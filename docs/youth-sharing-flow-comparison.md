# 청년부 나눔 순서와 진행 방식 비교

근거: 2026-10-25 오전 「빛의 자녀들처럼 행하라」에 대해 2026-10-27 직접 생성한 설교AI 최초 결과와 우리 서비스의 기존 생성 로그. 설교AI 내부 프롬프트·모델·일반 성능을 확인한 비교는 아닙니다. 대상 범위와 보조 입력이 달라 통제된 실험은 아닙니다.

## 흐름 비교와 반영

| 순서/방법 | 기존 우리 방식 | 이번 설교AI 결과 | 이번 반영 |
|---|---|---|---|
| 마음 열기 | 모든 설교에 같은 예배 감상 질문 | 손전등 비유와 이미 빛이라는 정체성을 이용한 여는 질문 2개 | 근황과 마음을 나누는 여는 질문 1개. 비유 속 소품의 사용 경험을 억지로 묻지 않음. 새 자료가 없으면 기존 질문 사용 |
| 말씀 읽기 | 성경/요약/질문 탭 | 본문·핵심 요약·참고 구절·풀이 제공 | 기존 탭 유지. 45분 진행안에서 본문·요약 읽기 시간을 따로 안내 |
| 이해 | 말씀 점검 2문항, 설명·답안 바로 표시 | 말씀 나눔 4문항 안에 관찰·해석·경험이 섞임 | 이해 → 성찰 분리 유지. 설교를 못 들었어도 성경 본문에서 답할 질문과 참고 도움 제공 |
| 경험·은혜 | 은혜 나눔 3문항. 공개 범위 선택 | 원문 비유와 미운 감정·걱정 등 생활 장면을 구체적으로 사용 | 3문항 유지. 최소 한 문항을 원문 생활 장면에 연결. 특정 경험·감정을 전제하지 않음 |
| 선택 심화 | 별도 심화 섹션 없음 | 추가 심화 1문항 | 질문 수를 늘리지 않고 기존 질문에 핵심 표시. 시간 부족 시 선택해서 진행 |
| 실천 | 행동 1가지와 서로를 위한 기도 요청 | 적용 2문항과 구체적 실천 2개 | 결단 2문항 유지. 원문 적용/서비스 제안을 구분한 선택지 1~2개 제공 |
| 기도 | 개인 기도제목 메모 | 함께 기도할 제목과 마무리 기도문 | 개인 메모를 유지하고 마무리 기도 초안을 접어 제공 |
| 리더 자료 | 이해 질문 설명과 답안 | 실행 당시 리더가이드 오류 | 성공하지 않은 기능의 품질을 추정하지 않음. 이번에는 핵심 질문·진행안·참고 도움을 보강 |

## 권장 진행: 45분

1. 마음 열기 5분: 모든 사람에게 긴 신앙 고백을 요청하지 않고 최근의 기쁨이나 마음 쓰이는 일 등 근황과 마음에서 시작합니다.
2. 본문·요약 읽기 5분: 설교를 못 들은 사람도 같은 맥락으로 들어올 수 있게 합니다.
3. 말씀 이해 8분: 질문에 안내된 성경 장절을 함께 읽고, 서로 생각한 뒤 참고 도움을 확인합니다. 시험처럼 정답을 말하게 하지 않습니다.
4. 삶 나눔 17분: 질문을 모두 끝내기보다 한 사람의 경험을 충분히 듣습니다. 핵심 질문을 먼저 선택하고, 말하기 어려운 질문은 넘어갈 수 있습니다.
5. 실천 선택 5분: 예시 중 하나 또는 자신의 상황에 맞는 행동 하나를 정합니다. 여러 숙제를 부과하지 않습니다.
6. 서로 기도 5분: 앞에서 나눈 실천과 부탁을 받아 기도합니다. 기도 초안은 필요할 때만 사용합니다.

인원·모임 시간에 따라 조정하는 시작안이며 실제 청년부 사용성 검증으로 확정된 시간은 아닙니다. 동일한 질문에 모두가 차례로 답하도록 강제하지 않고, 핵심 이해와 서로 듣기를 우선합니다.

## 유지한 판단과 바꾼 판단

우리의 이해 → 성찰 → 결단 순서는 유지했습니다. 설교AI처럼 경험 질문을 이해 단계에 섞거나 심화 질문을 추가하여 전체 문항을 늘리지는 않았습니다. 대신 기억하기 쉬운 원문 비유, 생활 장면의 구체성, 선택 가능한 실천과 마무리 지원을 받아들였습니다.

관찰·경험·적용을 한 문항에서 모두 요구하거나, 가족 관계와 감정을 미리 단정하는 방식은 도입하지 않습니다. 생성 결과에 실제로 이 원칙이 잘 반영되는지는 원문 사례를 늘려 사람과 함께 검토해야 합니다.
